# 신뢰성 체크리스트 (방아쇠 달린 과거 사고)

실제로 이 레포에서 난 사고를, **diff만 보고 걸러지는 방아쇠**와 함께 적어 둔 표다.
아무도 과거 사고를 외우지 않아도 되게 하는 것이 목적이다.

**쓰는 법**: 구현자·리뷰어·설계 검토자는 바뀐 파일과 바뀐 줄을 보고 **방아쇠가 걸리는 항목만** 고른다.
보통 3~10개다. 전부 읽지 않는다. 고른 항목은 PR 본문 "검증"에 번호로 적는다.

**늘리는 법**(규칙 정비자): ① 리뷰 지적·되돌리기에서 **두 번 이상** 나왔고 ② **diff에서 방아쇠를 읽을 수 있고**
③ 사고나 PR 번호로 근거를 댈 수 있을 때만 한 줄을 더한다. 한 줄을 더하면 낡은 줄이 있는지 같이 본다 —
목록은 놔두면 자라기만 한다.
